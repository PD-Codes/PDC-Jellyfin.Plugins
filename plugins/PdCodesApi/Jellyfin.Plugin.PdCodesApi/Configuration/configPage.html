The root of your PD-Codes API deployment, without the /v5 suffix — for example https://media.example.org/jikan. There is deliberately no default: this plugin will not send your library to a server you did not choose. Until this is set, every provider logs a warning and returns nothing.
An ISO code such as de, en or ja. Leave empty to use each library's own metadata language, which is usually what you want on a server with libraries in more than one language. Sent as an Accept-Language header.
An ISO 3166-1 alpha-2 code such as DE or US. Selects which streaming availability and which age rating apply. When empty, no age rating is imported at all — a rating from the wrong country would drive parental controls incorrectly.
Off is recommended. The API flags some matches as guesses made by comparing titles. Accepting one binds your library item to that work permanently — the item then looks correctly identified and is never re-checked, even when it is the wrong show.
Anime is not a separate item type in Jellyfin: an anime series is a Series and an anime film is a Movie. Both possible media are always tried; this only sets the order. Turn it on for a library that is mostly anime.
Anime files numbered straight through the whole run (Show - 62.mkv) are normally filed by Jellyfin under Season 1, so the plugin asks the API for S01E62. On a show whose seasons do not restart at 1 — One Piece season 2 is episodes 62–77 — that is a different, usually absent episode, and the file simply gets no metadata. With this on, such a miss is retried once as E62, and the answer is accepted only when the API reports that work's numbering as non-continuous. Season 1 and anime only. Cost: one extra request per episode that missed under both candidate types, paid once per episode — the absolute reference is then stored on the item, so later scans address it directly.
